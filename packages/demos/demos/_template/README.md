# Template: rooms by storey

The folder every demo starts from. A stacked bar of net floor area per storey, one segment per room, from the Duplex Apartment's `PSet_Revit_Dimensions.Area`.

- For: an architect checking how floor area is split.
- Data: `/data/duplex/elements.json` and `/data/duplex/parameters.json` (model data, no synthetic numbers).
- Run: `npm run demos` at the repository root, then `/demos/_template/`. The `_` prefix keeps it out of the index and the shared test.
